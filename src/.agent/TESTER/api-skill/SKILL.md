# API Skill Suite

A comprehensive collection of tools and guidelines for API design, testing, validation, and automation.

## Included Skills
- `api-to-testcase-generator`: Generate test cases from API definitions
- `api-analyzer`: Validate and debug API requests
- `api-designer`: REST API endpoint design and specification
- `postman`: Postman collection and testcase generation
- `newman`: Newman CI/CD test execution and report analysis
- `openapi-spec-generator`: Generate OpenAPI 3.x and Swagger 2.0 specs
